<header class="page-header"><p class="eyebrow">Network</p><h1>VALDR Testnet</h1><p class="lead">A controlled environment for validating software, protocol behavior and real peer-to-peer operation.</p></header>
<h2>Purpose</h2>
<p>Testnet is used to test synchronization, mining, transaction relay, wallet behavior, Explorer indexing, node restart behavior and network deployment before any separate Mainnet decision.</p>
<h2>Network profile</h2>
<p>The current Testnet profile is <strong>valdr-testnet-1</strong>. It uses P2P protocol v2, dedicated Testnet ports and Testnet-specific operational defaults.</p>
<h2>Testnet VDR</h2>
<p>Testnet units exist for protocol testing. They do not carry a project promise of financial value and do not define future Mainnet issuance or economics.</p>
<h2>Public rollout</h2>
<p>Distributed user-run Testnet rollout remains gated by Desktop and release readiness. The website must not present a public endpoint, seed or installer as available until it is deliberately published and verified.</p>
