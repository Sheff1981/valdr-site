<h1>About VALDR</h1>
<p class="lead">VALDR is an independent peer-to-peer blockchain network with VDR as its native digital currency.</p>
</header>

<p>The network operates with its own consensus rules, blockchain state, transaction model, peer-to-peer protocol, node software, wallet system, miner and block explorer.</p>

<h2>Transaction model</h2>
<p>VALDR uses a UTXO-based transaction model. Transactions consume existing unspent outputs and create new outputs. Each node independently validates transaction structure, ownership, signatures, available value and double-spend rules before accepting a transaction into local state.</p>

<h2>Proof of Work</h2>
<p>New blocks are produced through Proof of Work. A miner builds a candidate block, searches for a valid nonce and submits the resulting block to the network. Nodes independently verify the block, its transactions and its Proof of Work before accepting it into the active chain.</p>

<h2>Peer-to-peer operation</h2>
<p>The network is designed to operate without a central transaction server. Nodes discover peers, exchange transactions and blocks, synchronize chain state and independently determine the valid chain according to consensus rules.</p>

<h2>Development model</h2>
<p>VALDR development is divided into gated technical stages. Core blockchain functionality, storage, networking, synchronization, wallet security, mining and Explorer components are validated before later stages are treated as complete.</p>

<h2>Current stage</h2>
<p>The current development focus is Devnet and Testnet operation, software reliability and public-network readiness. Testnet VDR is used for protocol testing and does not define future Mainnet economics.</p>

<p>VALDR Mainnet is a separate future stage. Mainnet parameters, monetary policy and launch conditions require an independently approved specification before they can be treated as final.</p>

<h2>Project purpose</h2>
<p>The purpose of the project is to build a verifiable, independently operated blockchain system in which users can run nodes, create wallets, send signed transactions, mine blocks and verify network activity using open software.</p>
