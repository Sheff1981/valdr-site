<header class="page-header"><p class="eyebrow">About</p><h1>About VALDR</h1><p class="lead">VALDR is an independent Proof-of-Work blockchain with VDR as its native currency.</p></header>
<h2>A standalone network</h2>
<p>VALDR operates as its own blockchain network with independent consensus rules, chain state, peer-to-peer protocol, UTXO accounting, nodes, wallets, miners and block explorer.</p>
<h2>Open development</h2>
<p>The project is built in gated stages. Protocol, storage, networking, wallet security, mining, synchronization and Explorer work are validated before later release stages are treated as complete.</p>
<h2>Testnet first</h2>
<p>Current development is centered on Devnet/Testnet operation and software readiness. Testnet VDR is used for protocol testing and does not define future Mainnet economics.</p>
