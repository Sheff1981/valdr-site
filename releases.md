<header class="page-header"><p class="eyebrow">Software</p><h1>VALDR releases</h1><p class="lead">Only deliberate, verified artifacts should be presented as public releases.</p></header>
<h2>Release gate</h2>
<p>A public artifact needs an exact version, source revision, target operating system and architecture, file size, SHA-256 checksum and provenance information.</p>
<h2>Current status</h2>
<p>Cross-platform packaging and release pipeline work is in development. A public Testnet release remains gated by the required Desktop acceptance and deliberate release-candidate freeze.</p>
<h2>No placeholder binaries</h2>
<p>The website does not publish invented executable links. Until an artifact passes the release gate, the download surface remains informational.</p>
